# Fun with my Raspberry Pi 5

I bought a RP5 two years ago and I haven't really used it much. So I thought let me try out some fun CS concepts on this device and see what I can learn from this experience.

The goal of this blog was for me to learn. So I will not be using LLMs to code for me but I will be using them heavily to understand whats happening under the hood. So user discretion is advised that most of the source of truth in this blog comes from LLMs.
